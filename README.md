# 👋 Hi, I'm Daniel

### 💼 Software Developer & IT Consultant from Finland 🇫🇮

I'm a software developer currently studying at Hive Helsinki with a Bachelor's degree in Business IT from Haaga-Helia.

I enjoy building things that actually work and make sense! Both for the machine and the person reading the code next week. Whether it's Python, C, C++ or DevOps tooling, I focus on writing code that's clean, reliable and easy to understand.

I'm especially into automation, optimization, and scripting small tools that simplify messy workflows. I like figuring out how things work under the hood and building solutions that make life easier for teams, clients, or myself😝

If something feels repetitive, I’ll probably try to automate it.

- Automating boring stuff with scripts or bots
